ToDo Planner is an Android application for managing daily tasks and notes. Users can create, view, edit, and organize their tasks and notes through a simple and intuitive interface.

## Technologies
- **Language:** Java
- **UI:** XML
- **Platform:** Android
- **Database:** SQLite
- **IDE:** Android Studio
